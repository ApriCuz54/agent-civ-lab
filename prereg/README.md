# Pre-registration

`PREREG_A.md` and `PREREG_B.md` are written after the shared pilot and **committed before any
full-run data exists** (plan §6). The git commit timestamp is the evidence. After that commit,
any change to prompts, arms, metrics, exclusions or verdict rules goes in `DEVIATIONS.md` with a reason.
`phrase_sources.md` logs the public source (URL) of every T5 phrase-panel phrase.
