Verify EXECUTIVE_CLAIMS.csv against actual primary full texts and local implemented definitions. Existing independent sample covers eight of an earlier63-row claim ledger, not this executive set. All novelty-critical closest comparisons must be checked even where final direction is an assessment rather than an empirical law. Numerical local contrasts use existing report_audit and original eligibility/units; no new inference/reruns authorized. Final brief should avoid external numerical claims unless exact numerator/denominator/control is independently checked.

Each row gets supported within scope / overstated / incorrect / unresolved, exact source version/passages and code locators, whether existing independent check applies, and the permitted final wording. Remove or explicitly narrow inaccessible/unsupported claims, retaining original records and limitations. Method source access failure does not automatically settle the code concern. Do not treat overlap as blanket invalidity or uncentered bootstrap alone as proof of invalid tests.

Partition E01–E05, E06–E09, E10–E12 across up to three independent reviewers AFTER current cross-examination frees slots. Add any genuinely new claim introduced by cross-exam. Reviewers own separate Vault Verification/Executive_A/B/C directories. Coordinator reconciles, resolves material contradictions, canonicalizes source/claim records, freezes final matrix/options, and writes readable decision brief with explicit coverage gaps. G2 passes only for retained final claims, never because all sources were accessible or agents agreed.
