# Registry checkpoint
Provisional union of R1/R3/R9 authored packets. Original fields preserved in record_json, with stream provenance to avoid local-ID collisions. canonical_candidate groups arXiv versions but is not final DOI/version reconciliation. URL variants, author/dataset independence, missing schema fields and full-text labels must be reconciled before unique-coverage claims or random verification sampling. Every claim remains pending independent verification, including rows marked verified by their originating author. Wave2 files not included until completed and reviewed. This checkpoint does not claim 40–60 unique full texts or balanced coverage.
