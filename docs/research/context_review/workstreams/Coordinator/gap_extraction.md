## TrustFork — Mao et al., arXiv 2609.32635v1
[Primary text](https://arxiv.org/html/2609.32635v1), §§3.1–4,5.2–5.6, Appendix F. Displayed model/tier/family identity is separated from endpoint binding. A designated risky subagent operates in an executable workspace; consultation requirements, authority assignments and terminal harm are measured. Valid-trajectory conditioning and model-judged trajectories limit comparisons. Fixed retry policy retains the first valid run rather than selecting on safety. Identity manipulation is an established nearby mechanism comparator. Local T2 instead gives a checked accuracy panel, scripted worker deterioration, and confidence/verification notes; it measures selected-answer correctness, with no execution permissions. Broad novelty about rhetoric defeating evidence is therefore risky, while controlled temporal evidence/cue separation remains an unanswered local question. Artifact/code not independently audited.

## Agents' Overreliance — Yang et al., arXiv 2609.05587v2
[Primary text](https://arxiv.org/html/2609.05587v2), §§3–5, reproducibility statement. Corrupted search, subagent summaries and code output test adoption conditional on exposure; override additionally conditions on prior no-tool correctness. Prompt verification and metadata interventions distinguish contaminated-content rejection from clean utility. Categorical reliability labels can help within the tested search setup; numeric labels and model effects differ. Versioned API serving and conditional denominators limit transfer. Unlike T2, agents can call tools repeatedly and assess task content. This is a mechanism precedent, not a replication or matching percentage. Claimed released artifacts were not independently inspected; held-out/no-leak novelty assertions require additional audit.
